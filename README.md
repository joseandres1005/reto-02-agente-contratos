# Reto 02 — Agente de Registro de Contratos Vigentes

> Periferia IT Group · Perxia 2.0 · José Andrés Parra Ochoa

Agente conversacional completo en TypeScript que automatiza el registro de contratos desde un buzón único: clasifica correos, extrae datos con niveles de confianza, detecta duplicados y actualizaciones, registra en el maestro de SharePoint simulado, archiva documentos y genera alertas de vencimiento.
